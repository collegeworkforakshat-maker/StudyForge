# StudyForge Submission Checklist

## GitHub
Upload src/, tests/, docs/, README.md, statement.md, and .gitignore.
Do not upload .class files, out/, studyforge_data.txt, or Programiz_Main.java.

## Report PDF
Include the 15 required sections from the assignment: cover, introduction, problem statement, functional requirements, non-functional requirements, architecture, diagrams, design decisions, implementation, screenshots/results, testing, challenges, learnings, future enhancements, references.

## Screenshots
Capture: main menu, topics, dependency graph, cycle rejection, generated plan, progress update, regenerated plan, and ALL TESTS PASSED.
